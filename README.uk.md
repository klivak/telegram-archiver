# Telegram Archiver

[English](README.md) | **Українська**

Локальний open-source архіватор твого Telegram: особисті та приватні чати, групи, канали, медіа, Mini Apps, транскрипція голосових (Whisper) і AI-дайджест непрочитаного. Все зберігається на твоєму комп'ютері.

> ⚠️ Використовуй лише для власного акаунта. Поважай ліміти Telegram - надто агресивне вивантаження може призвести до обмежень акаунта. Не публікуй архіви з чужими повідомленнями.

## Можливості
- Вхід через QR-код за 30 секунд (або телефон + код + 2FA)
- Експорт особистих чатів, приватних груп і каналів, форумів, архіву - включно з чатами із забороною збереження (вмикається в налаштуваннях)
- Медіа з вибором типів, частинами, паузою, ретраями, докачкою
- Експорт одним файлом або частинами (місяць / розмір / токени для LLM) у MD, TXT, JSON(L), HTML, CSV
- Швидкий локальний пошук, пресети, власні теки за темами
- Mini Apps: знайти, відкрити, пройтись і зберегти знімки (MHTML, скріни, HAR, trace)
- Whisper локально: голосові й кружечки -> .txt/.srt
- Монітор непрочитаного (не позначає прочитаним) + AI-аналіз (Ollama локально / Anthropic / OpenAI)

## Швидкий старт
1. Отримай `api_id` і `api_hash` на https://my.telegram.org -> API development tools.
2. Завантаж реліз або збери сам (нижче) і запусти `TelegramArchiver.exe`.
3. Встав `api_id`/`api_hash` -> скануй QR у Telegram (Налаштування -> Пристрої -> Підключити пристрій).
4. Вибери чати -> "Експорт". Готово.

## Як працювати
| Задача | Де |
|---|---|
| Вивантажити всі особисті чати | Чати -> чип "Особисті" -> Вибрати всі -> Експорт |
| Лише документи за місяць | Експорт -> Медіа: Документи, Дати -> зберегти як пресет |
| Пауза завантаження | Завантаження -> ⏸ (або Space) |
| Telegram попросив чекати | Нічого не роби - таймер продовжить сам |
| Транскрибувати голосові | Чат -> ⋯ -> Транскрибувати все |
| Зберегти Mini App | Mini Apps -> Відкрити -> Записати / Автообхід -> Знімок |
| Ранковий дайджест | Монітор -> AI -> Розклад |

Архів: `Документи\TelegramArchiver\<акаунт>\` (змінюється в налаштуваннях).

## Запуск з вихідників (Windows)
Потрібні: Python 3.12 + [uv](https://docs.astral.sh/uv/), Node 20+ + pnpm.
```powershell
git clone https://github.com/<owner>/tgarchiver && cd tgarchiver
./scripts/build-frontend.ps1     # збирає UI всередину backend-пакета
cd backend; uv run tgarchiver    # відкриє http://127.0.0.1:8765
```
Dev-режим з гарячим перезавантаженням: `./scripts/dev.ps1` (backend `--dev` + Vite на http://localhost:5173). Усі перевірки: `./scripts/test.ps1`.

Опційні модулі (ставляться окремо, щоб базовий застосунок лишався малим):
- Транскрипція Whisper: `cd backend; uv sync --extra whisper`
- Знімки Mini Apps: `cd backend; uv sync --extra miniapps; uv run playwright install chromium`

## Секрети і `.env`

API ID/hash, сесія Telegram і AI-ключі вводяться в UI і зберігаються в системному keyring (Windows Credential Manager), не в репозиторії. Для dev/headless можна скопіювати `.env.example` у `.env` (ігнорується git) - значення з env використовуються лише як запасний варіант.

## Збірка exe
```powershell
# для Nuitka потрібні MSVC Build Tools
./scripts/build.ps1                     # frontend + Nuitka exe -> dist/TelegramArchiver.exe
./scripts/build.ps1 -Tool pyinstaller   # швидша dev-збірка
```
